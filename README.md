## 📚 Topics Covered

| Module | Description | Key Files |
| --- | --- | --- |
| **`01_basics`** | Core fundamentals, print statements, string concatenation, and I/O operations. | `01_hello.py` – `05_Boolean.py` |
| **`02_control_flow`** | Branching logic (`if/elif/else`) and iteration with `while` and `for` loops. | `06_Conditions.py` – `08_For_Loop.py` |
| **`03_data_structures`** | Built-in Python collections like lists and dictionaries. | `09_List.py`, `10_Dictionary.py` |
| **`04_functions_and_modules`** | Function definitions, constants, scope, and basic debugging workflows. | `11_Function.py` – `13_Debugging.py` |
| **`05_file_handling`** | Reading/writing text files and processing text corpora (`data/`). | `14_File.py` |
| **`06_oop`** | Classes, instances, instance methods, and special dunder (`__init__`, `__str__`, `__add__`) methods. | `15_Class.py` – `17_Dunder_methods.py` |

## 🚀 Getting Started

### Prerequisites

* Python **3.10+** (Python **3.11+** recommended for static type features like `typing.Self`).

### Running a Script

Clone the repository and run any lesson script directly from the root:

```bash
# Clone the repository
git clone [https://github.com/adhamzarif/Python.git](https://github.com/adhamzarif/Python.git)
cd Python

# Run any lesson
python3 01_basics/01_hello.py
python3 06_oop/17_Dunder_methods.py

```
